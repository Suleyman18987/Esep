# Есеп · веб-версия

Статическое приложение на HTML/CSS/JavaScript без внешних runtime-зависимостей, базы данных и регистрации. Математические модели перенесены из Android FinanceEngine.kt. Настройки сохраняются в localStorage; введённые суммы — только в памяти текущей вкладки.

## Локальный запуск

Запустить HTTP-сервер в этой папке: `python -m http.server 8080`, затем открыть http://localhost:8080. Открытие index.html напрямую как file:// не поддерживает ES-модули и установку PWA.

Проверка математики: `node --test tests/engine.test.js` (Node 18+).

## PWA и обновления

На iPhone открыть HTTPS-ссылку в Safari → Поделиться → На экран «Домой». На Android — меню браузера → Установить приложение. Один раз дождаться полной загрузки с интернетом, затем ресурсы доступны без сети.

Три manifest-файла выбирают значок для установки. Уже установленный значок управляется браузером/ОС и может потребовать повторного добавления.

При обновлении файлов нужно изменить версию CACHE в sw.js. Новая версия загружается в фоне; приложение предлагает кнопку «Обновить». Пользователь принимает перезагрузку, суммы текущей сессии не хранятся между перезагрузками.

Исходные 3D-атласы сохранены без изменений. Canvas выбирает семейство и меняет оттенок основного материала, сохраняя прозрачность и объём. Лицензия служебных иконок: assets/Lucide-LICENSE.txt.
